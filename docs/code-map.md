# Code map

Where to start for a given task on the `master` (3.x) line. Naming is load-bearing:
`BNC*` is an internal/support type, `Branch*` is a public-facing type or a server request,
and every `BNCServerRequest` subclass is named `Branch<Thing>Request`.

## Layout

- `Sources/BranchSDK/*.m` all implementations, flat.
- `Sources/BranchSDK/Public/` the public header surface. Adding here is a public API change.
- `Sources/BranchSDK/Private/` internal headers (`BNCServerAPI.h`, `BNCRequestFactory.h`, the `BNCPreferenceHelper` internals, the request subclasses).
- `Sources/Resources/` `PrivacyInfo.xcprivacy`, umbrella header, modulemap.
