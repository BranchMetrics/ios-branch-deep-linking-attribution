# Code map (4.0.0-beta)

Naming is load-bearing: `BNC*` is internal, `Branch*` is a public-facing type or a server
request. Everything is flat under `Sources/BranchSDK/`, with headers split by visibility:
`Public/` is the API contract, `Private/` is internal and holds
this line's `BNCServerRequestOperation.h`, `BranchRequestOpen.h` and `BranchRequestDeepLink.h`.
`Sources/Resources/` holds `PrivacyInfo.xcprivacy`, the umbrella header and the modulemap.
